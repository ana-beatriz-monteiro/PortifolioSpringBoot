Linguagens que conheço

Cada linguagem tem seu propósito. Aqui estão as tecnologias que já aprendi e utilizo em meus projetos.

Python

Linguagem versátil e de fácil aprendizado, muito usada em automação, análise de dados, IA e desenvolvimento web.

CSS

Responsável pela estilização das páginas, tornando a interface visual e organizada para o usuário.

JavaScript

Torna as páginas interativas e dinâmicas, sendo essencial para o desenvolvimento web no front-end e no back-end.

Java

Linguagem robusta e amplamente utilizada em aplicações corporativas, Android e sistemas de grande escala.

HTML

Define a estrutura das páginas web, organizando o conteúdo de forma semântica e acessível.

C

C

Linguagem de baixo nível, com foco em desempenho e controle de hardware, muito usada em sistemas operacionais e embarcados.

SQL

É a linguagem usada para manipular e consultar dados em bancos de dados relacionais.

PHP

Muito utilizada no desenvolvimento web, especialmente no back-end e em sistemas dinâmicos.
